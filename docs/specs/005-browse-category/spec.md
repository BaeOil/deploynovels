# Feature Specification: เรียกดูนิยายตามหมวดหมู่

**Feature ID:** `005-browse-category`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ Guest, Reader และ Writer สามารถเรียกดูนิยายตามหมวดหมู่ที่ต้องการได้

## 2. Scope

### In Scope

* แสดงหมวดหมู่ของนิยาย
* เลือกหมวดหมู่เพื่อเรียกดูนิยาย
* แสดงรายการนิยายที่อยู่ในหมวดหมู่ที่เลือก
* แสดงเฉพาะนิยายที่ผู้ใช้งานมีสิทธิ์เห็น

### Out of Scope

* การค้นหานิยายด้วยคำค้น
* รายละเอียดนิยาย
* การอ่านนิยาย
* แผนผังการอ่าน
* การบันทึกและอ่านต่อจากตำแหน่งเดิม
* ชั้นหนังสือ
* การติดตามนักเขียน
* การแจ้งเตือน
* การจัดการนิยายของ Writer
* การจัดการหมวดหมู่ของ Admin

## 3. Requirements

### R-CATBROWSE-01 — แสดงหมวดหมู่

ระบบต้องให้ผู้ใช้งานเรียกดูหมวดหมู่ของนิยายได้

**Traceability:** `FR-READ-02`

### R-CATBROWSE-02 — แสดงนิยายตามหมวดหมู่

เมื่อผู้ใช้งานเลือกหมวดหมู่ ระบบต้องแสดงรายการนิยายที่อยู่ในหมวดหมู่นั้น

**Traceability:** `FR-READ-02`

### R-CATBROWSE-03 — จำกัดนิยายตามสิทธิ์การเข้าถึง

ระบบต้องแสดงเฉพาะนิยายที่ผู้ใช้งานมีสิทธิ์เห็น

**Traceability:** `FR-READ-08`

## 4. Acceptance Criteria

* **AC-CATBROWSE-01** เมื่อผู้ใช้งานเปิดส่วนหมวดหมู่ ระบบต้องแสดงหมวดหมู่ที่สามารถเรียกดูได้
* **AC-CATBROWSE-02** เมื่อผู้ใช้งานเลือกหมวดหมู่ ระบบต้องแสดงรายการนิยายที่อยู่ในหมวดหมู่นั้น
* **AC-CATBROWSE-03** เมื่อหมวดหมู่ที่เลือกไม่มีนิยาย ระบบต้องแสดงสถานะว่าหมวดหมู่ไม่มีนิยาย โดยไม่แสดงนิยายที่ไม่อยู่ในหมวดหมู่นั้น
* **AC-CATBROWSE-04** นิยายที่ผู้ใช้งานทั่วไปไม่มีสิทธิ์เข้าถึงต้องไม่ปรากฏในรายการนิยายของหมวดหมู่

หมายเหตุ: `AC-CATBROWSE-03` เป็นข้อกำหนดเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม — `docs/SRS.md` (`FR-READ-02`) ไม่ได้ระบุพฤติกรรมกรณีหมวดหมู่ไม่มีนิยายไว้โดยตรง

## 5. Constraints

* การเรียกดูหมวดหมู่ต้องไม่รวมการค้นหาด้วยคำค้น
* รายการนิยายต้องเคารพสิทธิ์การเข้าถึงของ Guest, Reader และ Writer
* การเลือกนิยายจากรายการสามารถนำไปยัง `006-novel-detail`
* การอ่านนิยายอยู่ในขอบเขตของ `001-read-novel`

## 6. Traceability

หมายเหตุ: `AC-CATBROWSE-03` เป็นข้อกำหนดเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม โดยเชื่อมกับ `R-CATBROWSE-02` (ซึ่งอ้างอิง `FR-READ-02`) — `docs/SRS.md` ไม่ได้ระบุพฤติกรรมกรณีหมวดหมู่ไม่มีนิยายไว้โดยตรง

## 7. Open Questions

ไม่มีสำหรับขอบเขตของ Feature นี้ในขณะนี้ — ประเด็นกรณีหมวดหมู่ไม่มีนิยายได้รับข้อยุติจากเจ้าของโครงการแล้ว และถูกบันทึกเป็น `AC-CATBROWSE-03`
