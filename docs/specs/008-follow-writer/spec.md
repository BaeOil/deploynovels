# Feature Specification: ติดตามนักเขียน

**Feature ID:** `008-follow-writer`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ผู้ใช้งานสามารถติดตามนักเขียน และยกเลิกการติดตามนักเขียนได้

## 2. Scope

### In Scope

* ติดตามนักเขียน
* ยกเลิกการติดตามนักเขียน

### Out of Scope

* การค้นหานิยาย
* การเรียกดูนิยายตามหมวดหมู่
* รายละเอียดนิยาย
* การอ่านนิยาย
* การเลือกทางเลือกของเรื่อง
* การบันทึกและอ่านต่อจากตำแหน่งเดิม
* แผนผังการอ่าน
* การเพิ่มนิยายลงชั้นหนังสือและนำนิยายออกจากชั้นหนังสือ
* การแจ้งเตือน
* การสร้างและจัดการนิยายของ Writer
* การจัดการของ Admin

## 3. Requirements

### R-FOLLOW-01 — ติดตามนักเขียน

ระบบต้องให้ผู้ใช้งานที่เข้าสู่ระบบแล้วติดตามนักเขียนได้ และต้องไม่อนุญาตให้ Guest ติดตามนักเขียน

**Traceability:** `FR-FOLLOW-03`

### R-FOLLOW-02 — ยกเลิกการติดตามนักเขียน

ระบบต้องให้ผู้ใช้งานที่เข้าสู่ระบบแล้วยกเลิกการติดตามนักเขียนได้ และต้องไม่อนุญาตให้ Guest ยกเลิกการติดตามนักเขียน

**Traceability:** `FR-FOLLOW-04`

หมายเหตุ: เงื่อนไขการเข้าสู่ระบบและการไม่อนุญาตสำหรับ Guest เป็นข้อสรุปเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม — `docs/SRS.md` ระบุความสามารถด้านการติดตามนักเขียนไว้สำหรับบทบาท Reader ในหัวข้อ 2.1 (Guest ไม่รวมความสามารถนี้) แต่ `FR-FOLLOW-03`/`FR-FOLLOW-04` ไม่ได้ระบุเงื่อนไขการยืนยันตัวตนไว้โดยตรง

## 4. Acceptance Criteria

* **AC-FOLLOW-01** เมื่อผู้ใช้งานที่เข้าสู่ระบบแล้วติดตามนักเขียน ระบบต้องบันทึกการติดตามนักเขียนคนนั้น
* **AC-FOLLOW-02** เมื่อผู้ใช้งานที่เข้าสู่ระบบแล้วยกเลิกการติดตามนักเขียน ระบบต้องยกเลิกการติดตามนักเขียนคนนั้น
* **AC-FOLLOW-03** เมื่อ Guest (ยังไม่ได้เข้าสู่ระบบ) พยายามติดตามนักเขียนหรือยกเลิกการติดตามนักเขียน ระบบต้องไม่บันทึกการเปลี่ยนแปลงลงระบบ

หมายเหตุ: `AC-FOLLOW-03` เป็นข้อสรุปเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม — `FR-FOLLOW-03`/`FR-FOLLOW-04` ไม่ได้ระบุเงื่อนไขการยืนยันตัวตนไว้โดยตรง

## 5. Constraints

* การติดตามนักเขียนและการยกเลิกการติดตามนักเขียนไม่เปลี่ยนแปลงข้อมูลของนิยายของนักเขียน
* การเพิ่มนิยายลงชั้นหนังสือและนำนิยายออกจากชั้นหนังสืออยู่ในขอบเขตของ `007-bookshelf`
* การแสดงข้อมูลนักเขียนอยู่ในขอบเขตของ `006-novel-detail`
* เหตุการณ์ต้นทางที่เกี่ยวข้องกับการติดตามนักเขียนอยู่ในขอบเขตของ Feature นี้ และการแจ้งเตือนตาม `FR-NOTI-04` อยู่ในขอบเขตของ `011-notifications`

## 6. Traceability

| SRS Requirement | Spec Requirement | Acceptance Criteria |
| --------------- | ---------------- | ------------------- |
| `FR-FOLLOW-03`  | `R-FOLLOW-01`    | `AC-FOLLOW-01`, `AC-FOLLOW-03` |
| `FR-FOLLOW-04`  | `R-FOLLOW-02`    | `AC-FOLLOW-02`, `AC-FOLLOW-03` |

หมายเหตุ: `AC-FOLLOW-03` (เงื่อนไขการยืนยันตัวตนสำหรับ Guest) เป็นข้อสรุปเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม — `docs/SRS.md` ไม่ได้ระบุเงื่อนไขนี้ไว้ใน `FR-FOLLOW-03`/`FR-FOLLOW-04` โดยตรง

## 7. Open Questions

รายละเอียดต่อไปนี้ `docs/SRS.md` ไม่ได้ระบุ จึงยังไม่ถูกนำมาเขียนเป็น Requirement ใน Feature นี้ และต้องได้รับการตัดสินใจก่อน (ยกเว้นข้อที่ระบุว่าได้รับการตัดสินใจและบันทึกเป็น Requirement แล้ว)

* ~~ผู้ใช้งานต้องเข้าสู่ระบบก่อนจึงจะติดตามหรือยกเลิกการติดตามนักเขียนได้หรือไม่~~ — **ได้รับข้อยุติแล้ว:** ทั้งการติดตามและการยกเลิกการติดตามต้องเข้าสู่ระบบก่อน Guest ไม่สามารถใช้งานได้ (บันทึกเป็น `R-FOLLOW-01`, `R-FOLLOW-02`, `AC-FOLLOW-03`) — เป็นข้อสรุปเพิ่มเติมที่เจ้าของโครงการยืนยัน ไม่ใช่ข้อความที่ระบุไว้โดยตรงใน `FR-FOLLOW-03`/`FR-FOLLOW-04`
* บทบาทใดบ้างที่สามารถติดตามนักเขียนได้ (Reader, Writer, Admin)
* ผู้ใช้งานสามารถติดตามนักเขียนได้จากหน้าจอใดบ้างในระบบ
* ผู้ใช้งานหนึ่งคนสามารถติดตามนักเขียนได้สูงสุดกี่คน และมีการจำกัดจำนวนหรือไม่
* ระบบต้องแสดงสถานะ "กำลังติดตาม" ของนักเขียนให้ผู้ใช้งานเห็นหรือไม่
* ระบบต้องแสดงจำนวนผู้ติดตามของนักเขียนหรือไม่
* เมื่อผู้ใช้งานติดตามนักเขียนคนเดิมซ้ำ ระบบต้องจัดการอย่างไร
* หากนักเขียนที่ถูกติดตามสูญเสียสิทธิ์นักเขียน การติดตามเดิมของผู้ใช้งานจะเป็นอย่างไร
* มีการป้องกันการติดตามตัวเองหรือไม่
