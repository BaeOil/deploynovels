# Feature Specification: รายละเอียดนิยาย

**Feature ID:** `006-novel-detail`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ Guest, Reader และ Writer สามารถดูรายละเอียดของนิยายที่เลือกได้ ก่อนเข้าสู่การอ่านหรือใช้งานฟังก์ชันที่เกี่ยวข้อง

## 2. Scope

### In Scope

* แสดงรายละเอียดของนิยายที่ผู้ใช้งานเลือก
* แสดงข้อมูลของนักเขียน
* แสดงหมวดหมู่ของนิยาย
* แสดงคำโปรยและเรื่องย่อ
* แสดงข้อมูลที่เกี่ยวข้องกับนิยายตามที่ระบบกำหนดไว้

### Out of Scope

* การค้นหานิยาย
* การเรียกดูนิยายตามหมวดหมู่
* การอ่านเนื้อเรื่อง
* การเลือกทางเลือกของเรื่อง
* แผนผังการอ่าน
* การบันทึกและอ่านต่อจากตำแหน่งเดิม
* การสร้างหรือแก้ไขนิยาย
* การเผยแพร่นิยาย
* การจัดการของ Admin

## 3. Requirements

### R-DETAIL-01 — แสดงรายละเอียดนิยาย

ระบบต้องแสดงรายละเอียดของนิยายที่ผู้ใช้งานเลือก โดยข้อมูลต้องเป็นข้อมูลของนิยายเรื่องนั้น

**Traceability:** `FR-READ-03`

### R-DETAIL-02 — แสดงข้อมูลประกอบนิยาย

ระบบต้องแสดงข้อมูลประกอบของนิยาย ได้แก่ ชื่อเรื่อง ชื่อนักเขียน หมวดหมู่ คำโปรย และเรื่องย่อ

**Traceability:** `FR-READ-03` (รายการฟิลด์เป็นข้อกำหนดเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม — `docs/SRS.md` ไม่ได้ระบุรายการฟิลด์ไว้โดยตรง)

## 4. Acceptance Criteria

* **AC-DETAIL-01** เมื่อผู้ใช้งานเลือกนิยาย ระบบต้องแสดงหน้ารายละเอียดของนิยายเรื่องนั้น
* **AC-DETAIL-02** หน้ารายละเอียดต้องแสดงชื่อเรื่อง ชื่อนักเขียน หมวดหมู่ คำโปรย และเรื่องย่อของนิยาย
* **AC-DETAIL-03** ข้อมูลที่แสดงต้องเป็นข้อมูลของนิยายที่ผู้ใช้งานเลือก

หมายเหตุ: `AC-DETAIL-02` เป็นข้อกำหนดเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม — `docs/SRS.md` (`FR-READ-03`) ไม่ได้ระบุรายการฟิลด์ไว้โดยตรง

## 5. Constraints

* รายละเอียดต้องอ้างอิงจากนิยายที่ผู้ใช้งานเลือก
* การอ่านเนื้อเรื่องอยู่ในขอบเขตของ `001-read-novel`
* การค้นหาอยู่ในขอบเขตของ `004-search-novel`
* การเรียกดูตามหมวดหมู่อยู่ในขอบเขตของ `005-browse-category`

## 6. Traceability

| SRS Requirement | Spec Requirement | Acceptance Criteria            |
| --------------- | ---------------- | ------------------------------ |
| `FR-READ-03`    | `R-DETAIL-01`    | `AC-DETAIL-01`, `AC-DETAIL-03` |
| `FR-READ-03`    | `R-DETAIL-02`    | `AC-DETAIL-02`                 |

หมายเหตุ: แถว `R-DETAIL-02` — รายการฟิลด์ทั้ง 5 เป็นข้อกำหนดเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม — `docs/SRS.md` (`FR-READ-03`) ไม่ได้ระบุรายการฟิลด์ไว้โดยตรง

## 7. Open Questions

ไม่มีสำหรับขอบเขตของ Feature นี้ในขณะนี้ — ประเด็นรายการฟิลด์ที่ต้องแสดงได้รับข้อยุติจากเจ้าของโครงการแล้ว และถูกบันทึกเป็น `R-DETAIL-02`/`AC-DETAIL-02`
