# Feature Specification: การส่งรายงานและการจัดการรายงาน

**Feature ID:** `023-report`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ผู้ใช้งานส่งรายงานตามประเภทที่ระบบกำหนด และให้ Admin ตรวจสอบและจัดการรายงานจนถึงการระงับการเผยแพร่นิยายและการแจ้งเตือนผู้เกี่ยวข้อง

## 2. Scope

### In Scope

* ส่งรายงานตามประเภทที่ระบบกำหนด
* ตรวจสอบรายการรายงานโดย Admin
* จัดการสถานะของรายงานตามเงื่อนไขของระบบ
* ระงับการเผยแพร่นิยายที่ถูกรายงานเมื่อรายงานได้รับการอนุมัติ
* แจ้งเตือนผู้รายงานเกี่ยวกับผลการจัดการรายงาน
* แจ้งเตือนนักเขียนของนิยายที่ถูกรายงานเกี่ยวกับผลการจัดการรายงาน

### Out of Scope

* การยื่นคำขอปลดการระงับ
* การจัดการคำขอปลดการระงับโดย Admin
* การจัดการสถานะนิยายโดย Admin
* การส่งรายงานประเภทอื่นนอกเหนือจากที่ระบบกำหนด

## 3. Requirements

### R-REPORT-01 — ส่งรายงาน

ระบบต้องให้ผู้ใช้งานที่เข้าสู่ระบบแล้วส่งรายงานตามประเภทที่ระบบกำหนดได้ และต้องไม่อนุญาตให้ Guest ส่งรายงาน

**Traceability:** `FR-REPORT-01`

หมายเหตุ: เงื่อนไขการเข้าสู่ระบบและการไม่อนุญาตสำหรับ Guest เป็นข้อสรุปเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม — `docs/SRS.md` ระบุ `FR-REPORT-01` ไว้ว่า "ระบบต้องให้ผู้ใช้งานส่งรายงานตามประเภทที่ระบบกำหนดได้" โดยไม่ได้ระบุเงื่อนไขการยืนยันตัวตนไว้โดยตรง

### R-REPORT-02 — ตรวจสอบรายการรายงาน

ระบบต้องให้ Admin ตรวจสอบรายการรายงานได้

**Traceability:** `FR-REPORT-02`

### R-REPORT-03 — จัดการสถานะของรายงาน

ระบบต้องให้ Admin จัดการสถานะของรายงานตามเงื่อนไขที่ระบบกำหนด

**Traceability:** `FR-REPORT-03`

### R-REPORT-04 — ระงับการเผยแพร่นิยายที่ถูกรายงาน

เมื่อ Admin อนุมัติรายงานที่เกี่ยวข้องกับนิยาย ระบบต้องระงับการเผยแพร่นิยายดังกล่าวตามเงื่อนไขของระบบ

**Traceability:** `FR-REPORT-04`

### R-REPORT-05 — แจ้งเตือนผู้รายงาน

ระบบต้องแจ้งเตือนผู้รายงานเกี่ยวกับผลการจัดการรายงาน

**Traceability:** `FR-REPORT-05`

### R-REPORT-06 — แจ้งเตือนนักเขียนของนิยายที่ถูกรายงาน

ระบบต้องแจ้งเตือนนักเขียนของนิยายที่ถูกรายงานเกี่ยวกับผลการจัดการรายงาน

**Traceability:** `FR-REPORT-06`

## 4. Acceptance Criteria

* **AC-REPORT-01** เมื่อผู้ใช้งานที่เข้าสู่ระบบแล้วส่งรายงานตามประเภทที่ระบบกำหนด ระบบต้องรับรายงานนั้นของผู้ใช้งาน
* **AC-REPORT-02** เมื่อ Admin เปิดดูรายการรายงาน ระบบต้องแสดงรายงานที่ส่งเข้ามา
* **AC-REPORT-03** เมื่อ Admin จัดการสถานะของรายงาน ระบบต้องเปลี่ยนสถานะของรายงานนั้นตามเงื่อนไขที่ระบบกำหนด
* **AC-REPORT-04** เมื่อ Admin อนุมัติรายงานที่เกี่ยวข้องกับนิยาย ระบบต้องระงับการเผยแพร่ของนิยายเรื่องนั้นตามเงื่อนไขของระบบ
* **AC-REPORT-05** เมื่อรายงานได้รับการจัดการแล้ว ระบบต้องแจ้งเตือนผู้รายงานเกี่ยวกับผลการจัดการนั้น
* **AC-REPORT-06** เมื่อรายงานที่เกี่ยวข้องกับนิยายได้รับการจัดการแล้ว ระบบต้องแจ้งเตือนนักเขียนของนิยายเรื่องนั้นเกี่ยวกับผลการจัดการนั้น
* **AC-REPORT-07** เมื่อ Guest (ยังไม่ได้เข้าสู่ระบบ) พยายามส่งรายงานตามประเภทที่ระบบกำหนด ระบบต้องไม่บันทึกรายงานนั้นลงระบบ

หมายเหตุ: `AC-REPORT-07` เป็นข้อสรุปเพิ่มเติมที่เจ้าของโครงการยืนยันเพิ่มเติม — `FR-REPORT-01` ไม่ได้ระบุเงื่อนไขการยืนยันตัวตนไว้โดยตรง

## 5. Constraints

* รายงานต้องเป็นไปตามประเภทที่ระบบกำหนด
* การจัดการรายงานต้องเป็นไปตามสิทธิ์ของ Admin
* เมื่อรายงานได้รับการอนุมัติตามกระบวนการของระบบ นิยายที่เกี่ยวข้องต้องถูกระงับการเผยแพร่ตามเงื่อนไขของระบบ
* การยื่นคำขอปลดการระงับอยู่ในขอบเขตของ `024-unban-appeal`
* การจัดการสถานะของนิยายโดย Admin อยู่ในขอบเขตของ `025-admin-novel-management`
* การแจ้งเตือนตามระบบอยู่ในขอบเขตของ `011-notifications`

## 7. Open Questions

* รายงานมีประเภทใดบ้างที่ระบบกำหนด และแต่ละประเภทต้องใช้ข้อมูลใดในการส่งรายงาน
* ~~ผู้ใช้งานที่ส่งรายงานต้องเป็นผู้ใช้งานที่เข้าสู่ระบบแล้วหรือไม่~~ — **ได้รับข้อยุติแล้ว:** ต้องเป็นผู้ใช้งานที่เข้าสู่ระบบแล้ว Guest ไม่สามารถส่งรายงานได้ (บันทึกเป็น `R-REPORT-01`, `AC-REPORT-07`) — เป็นข้อสรุปเพิ่มเติมที่เจ้าของโครงการยืนยัน ไม่ใช่ข้อความที่ระบุไว้โดยตรงใน `FR-REPORT-01`
* สถานะของรายงานที่ระบบกำหนดมีสถานะใดบ้าง และสถานะใดที่อนุญาตให้ Admin ดำเนินการได้
* "อนุมัติรายงาน" หมายถึงการดำเนินการใดของ Admin และมีการดำเนินการอื่นที่ถือเป็นการอนุมัติหรือไม่
* เงื่อนไขของระบบที่กำหนดไว้สำหรับการระงับการเผยแพร่นิยายคืออะไร และสถานะของนิยายหลังระงับการเผยแพร่เป็นอย่างไร
* ผู้ใช้งานหนึ่งคนส่งรายงานเรื่องเดียวกันซ้ำได้หรือไม่
* ข้อมูลในการแจ้งเตือนผู้รายงานและนักเขียนต้องระบุผลการจัดการในระดับใด
